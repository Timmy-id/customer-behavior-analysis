# 🛍️ Customer Shopping Behavior Analysis

## Overview

This project analyzes **3,900 customer purchase transactions** to uncover insights into spending patterns, customer segments, product preferences, and subscription behavior.

The project follows an end-to-end data analytics workflow, starting with data preparation and exploratory analysis in **Python**, followed by **PostgreSQL SQL analysis**, **Power BI dashboard development**, business reporting, and presentation.

The goal is to transform raw customer transaction data into actionable insights that can support better **marketing, customer retention, subscription, and product strategies**.

---

## 📊 Dataset

The dataset contains:

* **3,900 rows**
* **18 columns**
* Customer demographics
* Purchase information
* Shopping behavior
* Subscription information
* Product and transaction details

### Key Features

* Age
* Gender
* Location
* Subscription Status
* Items Purchased
* Category
* Purchase Amount
* Season
* Size
* Color
* Discount Applied
* Previous Purchases
* Frequency of Purchases
* Review Rating
* Shipping Type

The dataset initially contained **37 missing values in the Review Rating column**.

## 1. 🐍 Data Loading & Exploratory Data Analysis

The dataset was loaded into Python using **Pandas**.

Initial analysis included:

* Dataset structure
* Data types
* Summary statistics
* Missing-value checks
* Data consistency checks
* Initial exploration of customer and purchase behavior

Functions such as `df.info()` and `df.describe()` were used to understand the dataset before cleaning.

---

## 2. 🧹 Data Cleaning & Feature Engineering

Several data preparation steps were performed in Python.

### Data Cleaning

* Checked for missing values
* Filled missing **Review Rating** values using the median rating for each product category
* Standardized column names using `snake_case`
* Checked for redundant columns
* Removed `promo_code_used` after determining it was redundant with `discount_applied`

### Feature Engineering

Two new features were created:

* `age_group` — customer age segmentation
* `purchase_frequency_days` — purchase frequency converted into days

The cleaned DataFrame was then loaded into PostgreSQL for further analysis.

---

## 3. 🗄️ PostgreSQL & SQL Analysis

PostgreSQL was used to perform structured business analysis on the cleaned dataset.

The SQL analysis answered questions including:

### Revenue Analysis

* Revenue generated by gender
* Revenue contribution by age group
* Average and total spending by subscription status

### Customer Analysis

* High-spending customers who used discounts
* Customer segmentation into:

  * New
  * Returning
  * Loyal
* Relationship between repeat purchases and subscriptions

### Product Analysis

* Top 5 products by average review rating
* Top 3 most-purchased products within each category
* Products with the highest percentage of discounted purchases

### Shipping Analysis

* Comparison of average purchase amounts between:

  * Standard shipping
  * Express shipping

A total of **10 business questions** were addressed through SQL analysis.

The analysis produced several actionable recommendations:

### 1. Boost Subscriptions

Promote exclusive benefits and incentives to encourage customers to subscribe.

### 2. Strengthen Customer Loyalty

Develop loyalty programs that reward repeat customers and encourage movement into the **Loyal** customer segment.

### 3. Review Discount Strategy

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Timmy-id/customer-behavior-analysis.git

cd customer-behavior-analysis
```

### 2. Install Python Dependencies

```bash
pip install pandas jupyter
```

### 3. Run the Python Analysis

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```text
customer-shopping-behavior-data-analysis.ipynb
```

Run the notebook sequentially to load, explore, clean, and transform the dataset.

### 4. Set Up PostgreSQL

Create a PostgreSQL database:

```sql
CREATE DATABASE customer_behavior;
```

Load the cleaned dataset into PostgreSQL.

Then execute the SQL queries in:

```text
customer-behavior-sql-queries.sql
```

### 5. Open the Power BI Dashboard

Open:

```text
customer_behavior_dashboard.pbix
```

Update the PostgreSQL connection if necessary and refresh the data.

### 6. Review the Report & Presentation

The business report and Gamma-generated presentation are also available in the repository
